➕ Adicionar GIFs

A galeria é gerada automaticamente a partir da pasta galeria/gifs/ no GitHub. Não há upload pela página — basta adicionar o ficheiro ao repositório:

  1. No GitHub, abre a pasta galeria/gifs
  2. Add file → Upload files e arrasta o(s) .gif
  3. Commit changes diretamente na main
  4. Aguarda ~1 min: a Action gera o manifest e o site atualiza sozinho

Ou, via terminal: cp ficheiro.gif galeria/gifs/ && git add galeria/gifs/ficheiro.gif && git commit -m "gif" && git push
